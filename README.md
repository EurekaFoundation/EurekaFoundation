# 💡 Eureka Suite

**Software libero, semplice, per tutti.**

Una raccolta di programmi open source e gratuiti, pensati per chi vuole strumenti
quotidiani senza abbonamenti, senza pubblicità e senza dover usare il terminale.

</div>

---

## I programmi

| | Programma | A cosa serve | Alternativa libera a |
|---|---|---|---|
| 🧭 | **[Viator](https://github.com/EurekaFoundation/viator)** | Browser web completo | Firefox, Chrome, Edge |
| 📓 | **[Libellus](https://github.com/EurekaFoundation/libellus)** | Quaderno digitale con scrittura a mano su tela infinita | OneNote, Freeform |
| 📰 | **[Charta](https://github.com/EurekaFoundation/charta)** | Impaginazione di volantini, brochure e locandine | Microsoft Publisher |
| 📅 | **[Kalendae](https://github.com/EurekaFoundation/kalendae)** | Calendario e gestione degli impegni | Google Calendar |

Tutti i programmi:

- si **installano con un doppio clic** su Windows, macOS e Linux;
- funzionano **anche offline**;
- condividono **lo stesso aspetto e le stesse impostazioni** (tema chiaro/scuro, lingua);
- usano **formati aperti** (PDF, SVG, iCalendar…), così i tuoi file restano tuoi.

## Perché i nomi latini?

*Viator* è il viaggiatore, *Libellus* il quaderno, *Charta* il foglio, *Kalendae* il primo
giorno del mese romano (da cui viene la parola "calendario"). Strumenti moderni con radici antiche.

## Contribuire

Ogni aiuto è benvenuto: segnalare un problema, tradurre, scrivere documentazione o codice.

1. Apri una *issue* nel repository del programma che ti interessa.
2. Le parti comuni a tutta la suite (tema, impostazioni, traduzioni, aggiornamenti)
   vivono in **[eureka-core](https://github.com/EurekaFoundation/eureka-core)**.
3. Il codice è scritto in **Python** con **PySide6 (Qt)**.
